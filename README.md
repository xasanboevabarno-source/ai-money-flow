# AI Money Flow

Локальное full-stack приложение для личного учёта финансов на Next.js, Drizzle и libSQL. Интерфейс на русском языке; регистрация не требуется.

## Запуск

Установите Node.js 20 или новее и npm. В каталоге проекта выполните:

```bash
npm install
cp .env.example .env.local
npm run db:migrate
npm run dev
```

В Windows вместо `cp` можно выполнить `copy .env.example .env.local`. Откройте http://localhost:3000. Без настройки создаётся локальная база `local.db`; таблицы также создаются при первом обращении к API. Файлы базы и `.env.local` исключены из Git.

## Turso

Создайте базу в [Turso](https://turso.tech/), получите URL базы и токен доступа в панели управления или через Turso CLI. Укажите в `.env.local`:

```env
TURSO_DATABASE_URL=libsql://адрес-базы
TURSO_AUTH_TOKEN=ваш-токен
```

Затем выполните `npm run db:migrate`. В локальном режиме используйте `TURSO_DATABASE_URL=file:local.db` и пустой токен. Обе базы используют одну схему.

## Gemini

Создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey) и укажите его только в `.env.local` вместе с моделью, например `GEMINI_MODEL=gemini-2.5-flash`. Перезапустите сервер после изменения переменных. Без ключа доступны ручной учёт, бюджеты, цели и аналитика. Распознанные операции нужно проверить и подтвердить до сохранения. Финансовые данные передаются в Gemini при запросе анализа; ключ остаётся на сервере.

## Учёт

Суммы операций вводятся в UZS. Настройки USD и RUB задают стоимость одной единицы валюты в сумах и меняют только отображение. Доступный баланс равен доходам минус расходы минус пополнения целей. Пополнение не создаёт расход. Удаление цели удаляет историю её пополнений и возвращает эту сумму в доступный баланс. Голосовой ввод зависит от поддержки Web Speech API браузером.

## Проверки

`npm run build`, `npm run lint`, `npx tsc --noEmit`. На сервере необходимо обеспечить приватный доступ к приложению и базе: встроенной авторизации нет. Деплой не настроен.
