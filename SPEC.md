# SPEC — AI Money Flow

Next.js App Router и TypeScript: клиентский интерфейс обращается к Route Handlers; сервер проверяет входные данные Zod и использует Drizzle ORM с @libsql/client. TURSO_DATABASE_URL по умолчанию file:local.db; облачная база использует токен. Миграции применяются командой db:migrate. Таблицы: categories, transactions, budgets, savings_goals, savings_contributions, ai_messages, settings. Денежные суммы хранятся в UZS; операции в других валютах пересчитываются по пользовательскому курсу при вводе. Баланс = доходы − расходы − пополнения целей; накопления = сумма пополнений. Бюджет относится к категории и месяцу. Gemini вызывается только на сервере, структурированный результат проверяется Zod; сохранение распознанных операций требует подтверждения. При отсутствии ключа ручные функции доступны.
